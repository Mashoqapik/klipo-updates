# Klipo

Klipo est une application **gratuite** pour Windows qui clippe tes parties en un clic.

Appuie sur **F8** : les 45 dernières secondes sont déjà enregistrées.

## Télécharger

**[⬇ Télécharger Klipo pour Windows](https://github.com/Mashoqapik/klipo-updates/releases/latest/download/Klipo-Setup.exe)**

Windows 10 et 11. Aucun compte, aucun abonnement. Klipo se met ensuite à jour tout seul.
